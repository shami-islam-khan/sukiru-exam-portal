# ⛩️ Sukiru Academy BD - JLPT N5 Interactive Exam Portal

An interactive, user-friendly, and lightweight Web Application designed for Japanese language learners to practice and test their proficiency for the **JLPT N5 Examination**.

---

## 🌟 Features

- 📚 **31 Comprehensive Modules:** Covers Hiragana, Katakana, Numbers, Object Counters, Time/Calendar, 25 Minna no Nihongo Lessons, and JLPT N5 Essential Kanji.
- ⚡ **Instant Exam Access:** Direct, clean navigation cards linking straight to specific practice test files.
- 📱 **Fully Responsive:** Optimized across desktop, tablet, and mobile devices with a smooth slide-out navigation menu.
- 🎨 **Modern Design:** Built using Tailwind CSS, high-contrast typography, custom Japanese-themed color palette (Torii, Sakura, Fox), and FontAwesome iconography.
- ⚡ **Fast & Lightweight:** Pure HTML/Tailwind implementation ensuring instant page loads without heavy framework overhead.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Icons:** FontAwesome v6
- **Hosting:** GitHub Pages
